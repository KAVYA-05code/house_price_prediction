# House Price Prediction using Linear Regression

## Project Overview
This project predicts house prices using a simple linear regression model.  
It uses features such as square footage, bedrooms, age of the house, and location score to estimate the final price.

## Features
- Data generation and exploration
- Data visualization with charts and heatmaps
- Linear regression model training
- Model evaluation using R2 score, MAE, and RMSE
- Actual vs predicted price plot
- Residual analysis

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
This project uses a synthetic dataset created in Python for demonstration purposes.

## Visualizations
- House price distribution
- Square footage vs price
- Bedrooms vs price
- Correlation heatmap
- Actual vs predicted prices
- Residual plot

## Model Evaluation
The model is evaluated using:
- R2 Score
- Mean Squared Error
- Root Mean Squared Error
- Mean Absolute Error

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Run all cells.
3. Download the generated plots and notebook.
4. Upload the files to GitHub.

## Sample Output
The model predicts house prices based on the input features and shows how well linear regression fits the data.
